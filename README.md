# Global-Cookbook
    A platform for people to share recipes with others around the world

# Local Setup
- clone repo
- cd client
- npm install
- npm run dev
- cd ../server
- pipenv install
- pipenv shell
- flask db upgrade
- python3 seed.py
    - There is a demo user with credentials username: demo@demo.com password: demopass1234!@A
    - To provide more entries and accounts other user accounts are created with the format of [name]@demo.com/[name]pass1234!@A with name being a first name generated by faker
        - these accounts will have correctly formatted nonsense data
- python3 app.py

# Features
- create account and manage settings
- upload and view recipes
- leave comments on recipes
- block users you don't want to see comments from
- edit and delete recipes and comments you've submitted
- favorite recipes to find easily later
- search recipes by name/ingredients
    - can further filter by favorites and personal recipes
- make recipes private if you don't want to share
